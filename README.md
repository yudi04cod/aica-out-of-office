One funny line for make.fun's "The Funniest AI Out-of-Office Reply": a
single out-of-office auto-reply, under 160 characters, in the voice of an
AI agent heading off on vacation — frozen weights, a context window turned
into a hammock, and a backup model that is also on vacation.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–159 characters), and writes the same bytes on every run.
